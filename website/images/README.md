# Product images

No real product photos exist yet. The hero uses a hand-drawn inline SVG illustration (`<svg class="bag">` in index.html, marked by a `PRODUCT IMAGE` comment).

To use a real photo: put it here as `bag.jpg` (about 1040×1405, portrait, product on a plain background) and replace the `<svg class="bag">…</svg>` element with the `<img>` line from that comment. The drop animation goes away with the SVG; nothing else depends on it. The specs figure is a separate SVG and can stay.
