# Logo explorations

Each file is a 48-unit mark with the monoline lowercase wordmark. Coral #E8654A + ink.

- **a-slot.svg**: Die-cut tote silhouette; the coral handle slot doubles as the bag's status light. Solid, engravable, reads as an object rather than an icon.
- **b-rim.svg**: Monoline tote whose opening is a coral line: the sensing rim items cross. Clean and friendly, but close to a generic shopping-bag glyph.
- **c-b-bag.svg**: Monogram: a lowercase b whose bowl is a bag, coral handle on top. Most letter-like and ownable, weakest at 16 px.
